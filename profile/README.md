### Flagships

- **[Koan](https://github.com/sylin-org/koan-framework)**, *the stack*. One grammar,
  `Entity<T>`, covers CRUD, REST, vector search, jobs, caching, and agent (MCP) tools, then
  tells you exactly what it wired up. Rails for .NET, shaped for development where coding
  agents write much of the code. .NET 10. &nbsp;`v0.17 · pre-1.0`
- **[Koi](https://github.com/sylin-org/koi)**, *the network*. A LAN toolbox: discover
  services, name them, trust them, serve them, all from one cross-platform binary with no
  accounts and no cloud. Label a container and the whole pipeline runs. Rust. &nbsp;`v0.9.0`
- **[Ghostlight](https://github.com/sylin-org/ghostlight)**, *the guardian*. Let an AI agent
  drive *your* real browser, logins, tabs, and sessions included, governed when you want it
  and wide open when you don't. Works from any MCP client. The engine is open source;
  organizations pay only for governance, never for autonomy. &nbsp;`v0.5.4 · open-core`
- **[Zen Garden](https://github.com/sylin-org/zen-garden)**, *the estate*. Turn the laptops
  and thin clients headed for landfill into self-hosted infrastructure that survives a
  machine dying: ask for services by type, never by hostname. Rust. &nbsp;`v0.2.0 · active`

**Also in the works**

- **Growing:** **[Agyo](https://github.com/sylin-org/agyo-tools)**, PowerToys for Koan (opt-in

  **[os-tools](https://github.com/sylin-org/os-tools)**, one symmetric Rust API over each OS's

- **Research:** **[Hokora](https://github.com/sylin-org/hokora)**, a cognitive architecture for

  **[Nagi](https://github.com/sylin-org/nagi)**, a breathing companion you hold, not watch.

### How Sylin works

- **Local-first.** Your hardware, your network. No accounts, no telemetry, no cloud in the
  critical path.
- **Open at the core.** The engines are open source and free to run. Where there's a paid
  layer, it governs how a tool is used; it never gates your ability to run it.
- **Candid.** Every project publishes its decision records, a maturity label, and a "when not
  to use this." Pre-1.0 is stated wherever it's true.

> Accounts required: **0** &nbsp;·&nbsp; Telemetry sent: **none** &nbsp;·&nbsp; Decisions documented: **600+ ADRs**
